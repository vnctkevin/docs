# Manage Services[#](#manage-services "Permanent link")

## Introduction[#](#introduction "Permanent link")

Hopsworks provides administrators with a view of the status/health of the cluster. This information is provided through the Services page.

## Prerequisites[#](#prerequisites "Permanent link")

Administrator account on a Hopsworks cluster.

### Step 1: Check service status[#](#step-1-check-service-status "Permanent link")

You can find the Services page by clicking on your name, in the top right corner of the navigation bar, and choosing _Cluster Settings_ from the dropdown menu and going to the _Services_ tab.

![services page](../../assets/images/admin/services/full.png)

Services page

This page give administrators an overview of which services are running on the cluster. It provides information about their status as reported by agents that monitor the status of the different Systemd units.

Columns in the services table represent machines in your cluster. Each service running on a machine will have a status _running_ (green) or _stopped_ (red). If a service is not installed on a machine it will have a status _not installed_ (gray).

### Step 2: Find a service[#](#step-2-find-a-service "Permanent link")

Services are divided into groups, and you can search for a service by its name or group. You can also search for machines by their host name.

![services](../../assets/images/admin/services/services.png)

Services

### Step 3: Manage a service[#](#step-3-manage-a-service "Permanent link")

After you find the correct service you will be able to **start**, **stop** or **restart** it, by clicking on its status.

![start services](../../assets/images/admin/services/start.png)

Start, Stop and Restart a service

Note

Stopping some services like the web server (glassfish\_domain1) is not recommended. If you stop it you will have to access the machine running the service and start it with `systemctl start glassfish_domain1`.

## Conclusion[#](#conclusion "Permanent link")

In this guide you learned how to manage services in Hopsworks.
