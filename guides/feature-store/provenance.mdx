# Provenance[#](#provenance "Permanent link")

## Introduction[#](#introduction "Permanent link")

Hopsworks feature store allows users to track provenance (lineage) between feature groups, feature views and training dataset. Tracking lineage allows users to determine where/if a feature group is being used. You can track if feature groups are being used to create additional (derived) feature groups or feature views.

You can interact with the provenance graph using the UI and the APIs.

## Step 1: Feature group lineage[#](#step-1-feature-group-lineage "Permanent link")

### Assign parents to a feature group[#](#assign-parents-to-a-feature-group "Permanent link")

When creating a feature group, it is possible to specify a list of feature groups used to create the derived features. For example, you could have an external feature group defined over a Snowflake or Redshift table, which you use to compute the features and save them in a feature group. You can mark the external feature group as parent of the feature group you are creating by using the `parents` parameter in the [get\_or\_create\_feature\_group](https://docs.hopsworks.ai/feature-store-api/3.7/generated/api/feature_group_api/#get_or_create_feature_group) or [create\_feature\_group](https://docs.hopsworks.ai/feature-store-api/3.7/generated/api/feature_group_api/#create_feature_group) methods:

### List feature group parents[#](#list-feature-group-parents "Permanent link")

You can query the provenance graph of a feature group using the UI and the APIs. From the APIs you can list the parent feature groups by calling the method [get\_parent\_feature\_groups](https://docs.hopsworks.ai/feature-store-api/3.7/generated/api/feature_group_api/#get_parent_feature_groups)

[Python](#__tabbed_3_1)

<pre><span></span><code><span class="n">lineage</span> <span class="o">=</span> <span class="n">transaction_fg</span><span class="o">.</span><span class="n">get_parent_feature_groups</span><span class="p">()</span>

<span class="c1"># List all accessible parent feature groups</span>
<span class="n">lineage</span><span class="o">.</span><span class="n">accessible</span>

<span class="c1"># List all deleted parent feature groups</span>
<span class="n">lineage</span><span class="o">.</span><span class="n">deleted</span>

<span class="c1"># List all the inaccessible parent feature groups</span>
<span class="n">lineage</span><span class="o">.</span><span class="n">inaccessible</span>
</code></pre>

A parent is marked as `deleted` (and added to the deleted list) if the parent feature group was deleted. `inaccessible` if you no longer have access to the parent feature group (e.g. the parent feature group belongs to a project you no longer have access to).

To traverse the provenance graph in the opposite direction (i.e. from the parent feature group to the child), you can use the [get\_generate\_feature\_groups](https://docs.hopsworks.ai/feature-store-api/3.7/generated/api/feature_group_api/#get_generated_feature_groups) method. When navigating the provenance graph downstream, the `deleted` feature groups are not tracked by provenance, as such, the `deleted` property will always return an empty list.

[Python](#__tabbed_4_1)

<pre><span></span><code><span class="n">lineage</span> <span class="o">=</span> <span class="n">transaction_fg</span><span class="o">.</span><span class="n">get_generated_feature_groups</span><span class="p">()</span>

<span class="c1"># List all accessible child feature groups</span>
<span class="n">lineage</span><span class="o">.</span><span class="n">accessible</span>

<span class="c1"># List all the inaccessible child feature groups</span>
<span class="n">lineage</span><span class="o">.</span><span class="n">inaccessible</span>
</code></pre>

You can also visualize the relationship between the parent and child feature groups in the UI. In each feature group overview page you can find a provenance section with the graph of parent feature groups and child feature groups/feature views.

## Step 2: Feature view lineage[#](#step-2-feature-view-lineage "Permanent link")

The relationship between feature groups and feature views is captured automatically when you create a feature view. You can inspect the relationship between feature groups and feature views using the APIs or the UI.

### Using the APIs[#](#using-the-apis "Permanent link")

Starting from a feature view metadata object, you can traverse upstream the provenance graph to retrieve the metadata objects of the feature groups that are part of the feature view. To do so, you can use the [get\_parent\_feature\_groups](https://docs.hopsworks.ai/feature-store-api/3.7/generated/api/feature_view_api/#get_parent_feature_groups) method.

[Python](#__tabbed_5_1)

<pre><span></span><code><span class="n">lineage</span> <span class="o">=</span> <span class="n">fraud_fv</span><span class="o">.</span><span class="n">get_parent_feature_groups</span><span class="p">()</span>

<span class="c1"># List all accessible parent feature groups</span>
<span class="n">lineage</span><span class="o">.</span><span class="n">accessible</span>

<span class="c1"># List all deleted parent feature groups</span>
<span class="n">lineage</span><span class="o">.</span><span class="n">deleted</span>

<span class="c1"># List all the inaccessible parent feature groups</span>
<span class="n">lineage</span><span class="o">.</span><span class="n">inaccessible</span>
</code></pre>

You can also traverse the provenance graph in the opposite direction. Starting from a feature group you can navigate downstream and list all the feature views the feature group is used in. As for the derived feature group example above, when navigating the provenance graph downstream `deleted` feature views are not tracked. As such, the `deleted` property will always be empty.

[Python](#__tabbed_6_1)

<pre><span></span><code><span class="n">lineage</span> <span class="o">=</span> <span class="n">transaction_fg</span><span class="o">.</span><span class="n">get_generated_feature_views</span><span class="p">()</span>

<span class="c1"># List all accessible downstream feature views </span>
<span class="n">lineage</span><span class="o">.</span><span class="n">accessible</span>

<span class="c1"># List all the inaccessible downstream feature views </span>
<span class="n">lineage</span><span class="o">.</span><span class="n">inaccessible</span>
</code></pre>
