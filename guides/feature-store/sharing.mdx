# Sharing[#](#sharing "Permanent link")

## Introduction[#](#introduction "Permanent link")

Hopsworks allows artifacts (e.g. feature groups, feature views) to be shared between projects. There are two main use cases for sharing features between projects:

*   If you have multiple teams working on the same Hopsworks deployment. Each team works within its own set of projects. If team A wants to leverage features built by team B, they can do so by sharing the feature groups from a team A project to a team B project.
    
*   By creating different projects for the different stages of the development lifecycle (e.g. a dev project, a testing project, and a production project), you can make sure that changes on the development project don't impact the features in the production project. At the same time, you might want to leverage production features to develop new models or additional features. In this case, you can share the production feature store with the development feature store in `read-only` mode.
    

### Step 1: Open the project of the feature store that you would like to share on Hopsworks.[#](#step-1-open-the-project-of-the-feature-store-that-you-would-like-to-share-on-hopsworks "Permanent link")

In the `Project Settings` navigate to the `Shared with other projects` section.

![Share Project](../../../../assets/images/guides/project/share_with_other_projects.png)

### Step 2: Share[#](#step-2-share "Permanent link")

Click `Share feature store` to bring up the dialog for sharing.

In the `Project` section choose project you wish to share the feature store with.

![Share Project Dialog](../../../../assets/images/guides/project/share_dialog.png)

Feature stores can be shared exclusively using `read-only` permission. This means that a member is not capable of enacting any changes on the shared project.

### Step 3: Accept the Invitation[#](#step-3-accept-the-invitation "Permanent link")

In the project where the feature store was shared (step 2) go to `Project Settings` and navigate to the `Shared from other projects` section. Click `accept`.

![Accept](../../../../assets/images/guides/project/accept.png)

After accepting the share, the shared feature store is listed under the `Shared from other projects` section.

![List of shared projects](../../../../assets/images/guides/project/list_of_shared_projects.png)

## Use features from a shared feature store[#](#use-features-from-a-shared-feature-store "Permanent link")

### Step 1: Get feature store handles[#](#step-1-get-feature-store-handles "Permanent link")

To access features from a shared feature store you need to first retrieve the handle for the shared feature store. To retrieve the handle use the get\_feature\_store() method and provide the name of the shared feature store

<pre><span></span><code><span class="kn">import</span> <span class="nn">hsfs</span>

<span class="n">connection</span> <span class="o">=</span> <span class="n">hsfs</span><span class="o">.</span><span class="n">connection</span><span class="p">()</span>

<span class="n">project_feature_store</span> <span class="o">=</span> <span class="n">connection</span><span class="o">.</span><span class="n">get_feature_store</span><span class="p">()</span>
<span class="n">shared_feature_store</span> <span class="o">=</span> <span class="n">connection</span><span class="o">.</span><span class="n">get_feature_store</span><span class="p">(</span><span class="n">name</span><span class="o">=</span><span class="s2">"name_of_shared_feature_store"</span><span class="p">)</span>
</code></pre>

### Step 2: Fetch feature groups[#](#step-2-fetch-feature-groups "Permanent link")

<pre><span></span><code><span class="c1"># fetch feature group object from shared feature store</span>
<span class="n">shared_fg</span> <span class="o">=</span> <span class="n">shared_feature_store</span><span class="o">.</span><span class="n">get_feature_group</span><span class="p">(</span>
    <span class="n">name</span><span class="o">=</span><span class="s2">"shared_fg_name"</span><span class="p">,</span>
    <span class="n">version</span><span class="o">=</span><span class="s2">"1"</span><span class="p">)</span>

<span class="c1"># fetch feature group object from project feature store</span>
<span class="n">fg_a</span> <span class="o">=</span> <span class="n">project_feature_store</span><span class="o">.</span><span class="n">get_or_create_feature_group</span><span class="p">(</span>
    <span class="n">name</span><span class="o">=</span><span class="s2">"feature_group_name"</span><span class="p">,</span>
    <span class="n">version</span><span class="o">=</span><span class="mi">1</span><span class="p">)</span>
</code></pre>
